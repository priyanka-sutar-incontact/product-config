# Product Configuration Repository\n\n## Overview\nThis repository contains product license and feature configuration for the Certificate Management System.\n\n## Recent Changes\n\n### SC-83567: MTLS License Integration\n- **License**: mtls\n- **Feature Toggle**: mtlsFt\n- **Permissions**: certificate:create, certificate:update, certificate:get\n- **OOTB Configuration**: Administrator role with userOOTB type\n\n## Directory Structure\n```\n├── licenses/          # License configuration files\n│   └── mtls.json\n├── feature-toggles/   # Feature toggle configurations\n│   └── mtlsFt.json\n├── permissions/       # Permission definitions\n│   └── certificate-permissions.json\n└── config/            # Main product configuration\n    └── product-config.json\n```\n\n## Configuration Files\n\n### License Configuration (licenses/mtls.json)\nDefines the MTLS license with associated permissions and feature toggles.\n\n### Feature Toggle (feature-toggles/mtlsFt.json)\nControls the availability of MTLS certificate management features.\n\n### Permissions (permissions/certificate-permissions.json)\nDefines granular permissions for certificate management operations.\n\n## Usage\nThese configuration files are used by the product system to enable license-based feature access and permission management.\n
